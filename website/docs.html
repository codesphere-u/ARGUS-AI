ARGUS AI Documentation

Run the 7-agent investment committee offline in deterministic paper mode, replay Trade Passports, or expose tools over MCP.

1. Installation

git clone https://github.com/codesphere-u/ARGUS-AI.git
cd ARGUS-AI
uv sync --extra dev

2. CLI Workflows

argus adversarial-demo
argus single --ticker NVDA --regime CHOPPY --vix 24
argus kill-switch --trigger-kill

3. Backtest & Passport Replay

argus backtest --ticker NVDA --bars 120 --regime CHOPPY --vix 26
argus replay --passport argus_ai/data/passports/PASSPORT-20261109-1F5BB2.json

4. MCP JSON-RPC 2.0 Server

Start the stdio MCP server with argus mcp to expose argus_convene_committee, argus_emergency_kill_switch, and alpaca_get_portfolio_telemetry.

5. HTTP Workbench

argus serve --host 127.0.0.1 --port 8080
