## 🎯 The Core Value Proposition (The Hook)

Most AI trading agents blindly predict direction and execute trades without questioning their own biases. When market conditions shift into low-liquidity traps or overbought blow-offs, these bots suffer catastrophic drawdowns.

**ARGUS AI 2.0 solves this with Institutional Self-Dissent & Continuous Learning**:
- **7-Agent Investment Committee**: Every trade is actively stress-tested by a dedicated **Devil's Advocate**.
- **Adaptive Bayesian Weights**: Agents that make winning calls earn higher voting power over time through continuous online learning.
- **Unilateral VETO Power**: If a trade setup contains structural traps, the Devil's Advocate exercises a hard VETO or downsize.
- **Official Model Context Protocol (MCP)**: Native tools for Claude Desktop, Cursor, and AI agents.
- **Deterministic 1.5x ATR Stops**: Bracket orders dispatched directly to **Alpaca** with immutable **Trade Passports**.
- **Emergency Kill Switch**: Institutional circuit breakers that freeze execution on drawdown breaches.

## 💡 Judge Q&A Cheat Sheet

**Q: What makes this different from single-agent LLM trading prompts?**  
**A:** Multi-agent adversarial separation prevents groupthink. A single prompt averages out contradictions; dedicated domain agents (Quant, News, Macro, Options) deliberate independently, while the Devil's Advocate is rewarded purely for finding flaw vectors and risk traps.

**Q: How does ARGUS AI integrate with the Alpaca ecosystem?**  
**A:** We use the Alpaca Trading API for real-time account telemetry, historical market data fetching, bracket order execution, and provide an official Model Context Protocol (MCP) server for agentic tool use.

**Q: How do Adaptive Bayesian Weights work?**  
**A:** When trades close, the Audit Agent attributes the PnL back to each agent's thesis. Agents with high predictive precision gain larger voting shares, while underperforming agents see their voting weight systematically diminished.
